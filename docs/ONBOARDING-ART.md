# ObGynVault: ChatGPT image prompts for the "Getting started" screens

> Status: the four images were made in ChatGPT and added on 2026-11-27. They live in `src/assets/onboarding/*.webp`; to change one, replace that file.

These images are optional. The app already has built-in artwork, and any image you send will replace the artwork on its screen.

**How to use these prompts**
1. Paste one prompt at a time into ChatGPT (image generation).
2. Ask for a **square 1024 × 1024 image** with **no text**. ChatGPT often adds random letters, so ask it to remove them.
3. Download the image and send it back to me with the file name given below (PNG is fine; I'll convert it to WebP).

**Common style for every image**, so all four look like one set:
- Flat, modern vector illustration with soft shapes, gentle shadows and rounded corners. A premium health-app look.
- Brand colours: navy #102A43, teal #20A69A, amber #E5A34C, white.
- Calm and professional, with lots of empty space. The subject sits in the centre.
- Show an Indian woman doctor where a person appears. Keep it respectful; no gore and no anatomy close-ups.
- No words, no letters, no logos, no watermarks.
